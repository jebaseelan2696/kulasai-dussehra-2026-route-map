# Kulasai Dussehra 2026 – Route & Contingency Map

Interactive briefing map for the Thoothukudi (TUT) and Tirunelveli (TIN) vehicle entry routes to Kulasekarapattinam, with congestion contingencies, SDPO parking-release options and the parking register.

- `index.html` – main briefing map (copy of `Kulasai-2026-Interactive-Map-ChatGPT.html`)
- `Kulasai-2026-Interactive-Map-ChatGPT.html` – working file for the main map
- `Finalized-TIN & TUT Route.kmz` – source KMZ (route lines, junctions, parkings)
- `seidunganallur-route.kml` – the TIN approach road, supplied separately from the KMZ
- `important-points.kml` – briefing points not present in the KMZ
- `lines-to-parkings.kml` – the roads from the routes into each parking place
- `Vehicle-Entry_Route-ECR Route.kmz` – ECR approach from Uvari, with the Tisayanvilai feeder
- `Vehicle-Entry_Route-Ramasamy Dharmapuram.kmz` – Ramasamy Dharmapuram approach
- `Vehicle-Entry_Route-Ramakrishna School Route.kmz` – Ramakrishna School Jn. approach and its feeders
- `Vehicle Exit Route 2.kmz` – outward route from the parking zone
- `Kulasai_Dussehra_Route_Contingency_Map.html` – earlier Claude version (reference only)
- `TIN_TUT_Route_Roadmap.html` – earlier roadmap version
