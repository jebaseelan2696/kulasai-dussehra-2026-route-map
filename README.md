# Kulasai Dussehra 2026 – Route & Contingency Map

Interactive briefing map for the Thoothukudi (TUT) and Tirunelveli (TIN) vehicle entry routes to Kulasekarapattinam, with congestion contingencies (A1–A5, B1–B2, C1) and SDPO parking-release options.

- `index.html` / `Kulasai_Dussehra_Route_Contingency_Map.html` – current briefing map (same file)
- `Finalized-TIN & TUT Route.kmz` – source KMZ (route lines, junctions, parkings)
- `TIN_TUT_Route_Roadmap.html` – earlier roadmap version
- `Kulasai-2026-Interactive-Map-ChatGPT.html` – ChatGPT concept version (animated movement idea, adopted into index.html)
